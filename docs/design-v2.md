# 创作工具馆 · 第二版设计

采用 Anthropic 官方 [frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design) 的设计方法。

目标：让用户先找到能用的 Skill，再研究项目证据。视觉选择冷白、墨蓝、钴蓝，紧凑的中文排版和大字号英文工具名。首页的记忆点是三块视频创作工具展示，配合剪辑时间线的几何图形；不使用通用渐变背景、虚构的热度数字或密集的独立统计卡片。

信息层级：Skills / 开源应用工具 → 用途 → 热度筛选。主卡片整块可访问，收藏是独立按钮。详情页以真实 README 为主体，观测指标为辅助。移动端展示区上下排列，筛选可横向滚动，代码和表格局部滚动。

实施前自查：避免将所有项目包装成视频技能；只把有技能文件或安装依据的项目列入 Skills。推荐展示与热门排序明确区分。没有中文源文件时不伪造翻译。
